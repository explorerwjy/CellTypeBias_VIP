## 4. P-value Calculation

| Field | Detail |
|---|---|
| **Manuscript claim** | Statistical significance is assessed via an empirical permutation test comparing observed bias against 10,000 null simulations, with FDR correction. |
| **Code location** | `src/CellType_PSY.py`: `GetPermutationP_vectorized()` (line 1957); called by `AddPvalue_vec()` in `scripts/script_bias_cal.py` (line 20) |
| **P-value formula** | `p = (count + 1) / (n_valid + 1)` where `count = sum(observed <= null)` for each cell type (one-sided, testing for enrichment, i.e., observed > null). The +1 in numerator and denominator is the standard conservative correction for empirical p-values (line 1979). |

## 5. Specificity Score Computation (TPM -> Specificity -> Centering)

| Field | Detail |
|---|---|
| **Manuscript claim** | Expression specificity is computed as fold-enrichment of TPM, capped, filtered for lowly-expressed genes, and mean-centered per cell type. |
| **Code location** | `notebooks/notebook_preprocessing.py` (lines 52-223) |
| **Step 1: TPM** | `TPM = (raw_expression / column_sum) * 1e6` per cell type (line 71) |
| **Step 2: TPM filtering** | Values < 0.1 TPM set to 0 (line 107, `min_tpm=0.1` at line 122) |
| **Step 3: Specificity** | `S_g_ct = filtered_TPM_g_ct / sum_ct(filtered_TPM_g_ct) * N_ct` where N_ct = 461 (line 112: `specificity_df = filtered_tpm.div(gene_total_tpm, axis=0) * specificity_df.shape[1]`). This is fold-enrichment: specificity = 1.0 means gene is uniformly expressed; >1.0 means enriched. |
| **Step 4: Clipping** | `clip(lower=0, upper=2*mean_specificity)` where `mean_specificity = mean(all values)` (line 133-134). For 461 cell types, mean specificity ~= 1.0, so cap ~= 2.0. |
| **Step 5: Low-expression filter** | Remove genes with overall expression < 10,000 (line 169-174, 220). This filters ~5,000 lowly-expressed genes with high fraction of zeros. |
| **Step 6: Mean centering** | `S_centered_g_ct = S_g_ct - mean_ct(S_g_ct)` per cell type column (line 207-213, 222). This removes cell-type-level baseline specificity (some cell types have higher average specificity due to more restricted transcriptomes). |
| **Output file** | `HumanCT.TPM.0.1.Filt.Spec.clip.lowexp.cut1e4.mean_centered.csv` |
